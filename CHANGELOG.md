# Changelog

## Unreleased
- Default bookmarks are now the start page quick links; untouched old default bookmarks are replaced, customized ones are kept.
- The floating mic (voice search) button shows only on YouTube pages.
- Android Automotive: hide the extra media tile in the car launcher and allow the browser while driving (when installed from a permitted store).
- Support Android 11/API 30 and newer (was Android 15), so the same APK installs on Android Automotive OS 11 head units.
- Add an eye button beside the temporary controls that hides the menu button and media controls immediately.
- Fade bottom sheets while they are being dragged (opacity configurable under In-app controls, default 20%) so the page behind stays visible.
- Add a Mixes tab on YouTube pages that lists the signed-in user's mixes (thumbnail and title); tapping one plays it and maximizes the player once it is playing.
- Add a large mic button beside the temporary controls: speak a query to open the YouTube results for it.
- Remember whether media was playing maximized and restore that together with the playback position.
- A maximized video keeps playing when the browser window is hidden (Android Auto split-screen tile left for the map, phone app in the background).
- Android Auto (fullscreen entry): keep playing when the head unit hides Android Auto (native car UI in front); the browser is parked off-screen instead of destroyed and reattached when Android Auto returns.
- Preserve browser media playback when the host loses focus, and save/restore the media position if the page is recreated.
- Correct YouTube next/previous availability and actions using the player controls, including hiding unavailable actions on Shorts.
- Add a fullscreen player control for pages with a supported fullscreen button; reveal media controls and the menu FAB on touch during fullscreen playback.
- Keep text entered with the Android Auto keyboard actionable even when no search suggestions are returned.
- Update the default start-page sites.
- Keep media playing in the background when the app is not on top, on the phone and in Android Auto.
- Previous restarts the current video when it is more than 10 seconds in; otherwise it goes to the previous item.
- Long-pressing next/previous (car keys and on-screen buttons) seeks forward/backward; a tap still skips.
- Add media resumption support: the last played page is offered as a resumable item and playing it reopens the browser. Android Auto does not currently use this to pick its startup media source.
- Fix next/previous taps being treated as long presses (always seeking), and on-screen buttons acting on the other browser when the phone and car browsers are both open.
- Fix holding an on-screen next/previous button continuing to seek after release.
- In portrait, show the fullscreen control above the menu button, at the same size as the media controls.
- CI now versions the app with semantic versioning: each main build bumps only the PATCH of the latest `vX.Y.Z` tag and publishes a `vX.Y.Z` release; major/minor bumps are made by pushing a `vX.Y.Z` tag manually, which builds and releases that exact version. The version code is derived from the version. Local builds use the next patch after the latest tag with a `-dev` suffix, so they install over CI builds (same signing key).
- Rebranded the fork as AA Browser Motion, maintained by carlosrpg.
- Added automated main-branch APK prereleases through GitHub Actions.
- Added a startup safety notice with a persistent "Don't show again" option.
- Disabled the upstream project's analytics endpoint in this fork.
- Added new User Agent profiles (Firefox, Edge, Samsung Internet).
- Added a Custom User Agent profile with user-defined string.
